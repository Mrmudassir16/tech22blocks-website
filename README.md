## 🛠️ Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Production build
npm run build

# 4. Start production server
npm run start
```

## ☁️ Deployment Guide

### Deploying to Vercel
1. Push your repository to **GitHub**:
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of Tech22Blocks corporate website"
   git branch -M main
   git remote add origin https://github.com/your-username/tech22blocks.git
   git push -u origin main
   ```
2. Import the repository in [Vercel](https://vercel.com):
   - **Framework Preset:** Next.js
   - **Root Directory:** `./`
   - **Build Command:** `next build`
   - **Output Directory:** `.next`
3. Click **Deploy**. Vercel will build and assign the custom production domain (`tech22blocks.in`).
